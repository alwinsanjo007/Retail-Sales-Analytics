# Retail Sales Analytics Dashboard

## Project Overview

Built an end-to-end Retail Sales Analytics solution using PostgreSQL and Power BI.

The project analyzes retail transactions to uncover sales trends, customer behavior, product performance, regional insights, and discount effectiveness.
